A script needs tools to live on screens.

Tulu-Tigalari is the historic script of the Tulu language. For it to be used every day, people need to be able to type it and to see it displayed properly on their phones and websites.

  • Type it

    Tulu Keyboard lets you type Tulu-Tigalari on your Android phone in any app.

  • Read it on your phone

    Tulu Lipi Lens reads Tulu-Tigalari text on your Android screen with an overlay.

  • See it on the web

    The Tulu Lipi extensions show Tulu-Tigalari text correctly on every website in Firefox, Chrome and Edge.
